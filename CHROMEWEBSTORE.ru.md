VPS Dashboard

Лёгкое, ориентированное на приватность расширение Chrome для управления VPS-серверами у разных провайдеров и панелей управления.

Управляйте своими серверами прямо из боковой панели браузера — проверяйте статус, использование ресурсов, трафик и выполняйте действия питания, не открывая множество панелей провайдеров.

LOCAL-FIRST. БЕЗ АККАУНТА. Ваши API-ключи никогда не покидают ваш браузер.

ПОЧЕМУ VPS DASHBOARD?

- Единая панель для всех ваших VPS
- Быстрый доступ из боковой панели Chrome
- Архитектура local-first — данные серверов и учётные данные остаются на вашем устройстве. В Google Analytics отправляются только анонимные, неидентифицирующие события использования, и вы можете отключить это в любой момент в настройках.
- Поддержка нескольких провайдеров
- Создано для пользователей VPS, а не для корпоративного мониторинга

VPS Dashboard фокусируется на управлении со стороны провайдера, а не на мониторинге на уровне ОС. Он дополняет специализированные инструменты мониторинга — но не заменяет их.

ПОДДЕРЖИВАЕМЫЕ ПРОВАЙДЕРЫ

Подключайтесь к 9 провайдерам. Некоторые стабильны, другие экспериментальны — подробности смотрите в руководствах по настройке внутри расширения.

КЛЮЧЕВЫЕ ФУНКЦИИ

Поддержка нескольких провайдеров
Подключайтесь к нескольким провайдерам VPS через специальные API-драйверы. Управляйте ими всеми из единого интерфейса.

Просмотр ресурсов со стороны провайдера
Показывайте статус, память, диск, трафик, IP, имя хоста, ОС и многое другое — всё через API вашего провайдера.

Умное управление питанием
Запускайте, останавливайте и перезагружайте серверы прямо из всплывающего окна (если поддерживается провайдером). Диалоги подтверждения предотвращают случайные действия. Действия питания адаптируются к состоянию сервера у каждого провайдера (например, переходные состояния, такие как «pending» или «stopping», определяются автоматически).

Пакетные операции
Обновляйте, перезагружайте или выключайте несколько серверов одновременно. Результаты выводятся отдельно для каждого.

Теги и поиск
Организуйте серверы с помощью пользовательских тегов. Фильтруйте и ищите, чтобы находить их мгновенно.

Сервер по умолчанию
Задайте сервер по умолчанию, который загружается автоматически при открытии расширения.

Режим приватности
Скрывайте IP-адреса, имена хостов и чувствительные данные одним нажатием — безопасно для скриншотов и демонстрации экрана.

Импорт / экспорт конфигурации
Экспортируйте свою конфигурацию в виде резервной копии JSON. Импортируйте её при смене браузера или устройства.

Напоминания об истечении срока
Расширение проверяет ваши серверы каждые 6 часов и уведомляет за 30, 7 и 3 дня до истечения срока. Об истёкших серверах напоминает ежедневно, пока они не будут продлены. Включены глобальный главный переключатель и отказ от уведомлений для каждого сервера.

Автоматические даты истечения
Для провайдеров, которые предоставляют даты биллинга, дата извлекается автоматически. Ручной ввод всегда имеет приоритет.
Данные API могут быть неточными — проверяйте их.

Экспорт в календарь (.ics)
Экспортируйте серверы в файл календаря .ics с напоминаниями на каждом пороге. Импортируйте в Google Calendar, Apple Calendar, Outlook или любой совместимый календарь.

Тёмная тема
Включены светлая и тёмная темы.

ПРИВАТНОСТЬ

- Локальная обработка — информация о серверах работает в вашем браузере; в Google Analytics отправляется только анонимная аналитика
- Аккаунт не требуется — без регистрации
- Не собираются API-ключи, учётные данные или чувствительные данные
- Прямые вызовы API к вашему провайдеру — запросы к серверу идут напрямую к провайдеру; единственный запрос к третьей стороне — это опциональная анонимная аналитика
- Конфигурация сервера и учётные данные хранятся в локальном хранилище Chrome

АНОНИМНАЯ АНАЛИТИКА

Расширение может отправлять анонимные события использования функций (например, открытие расширения, нажатие обновить/перезагрузить, просмотр руководства) в Google Analytics. Эти события содержат только название функции и тип провайдера — никогда API-ключи, учётные данные, имена хостов или содержимое сервера. Как и при любом запросе к стороннему сервису, Google получает сетевой IP, с которого отправлено событие; мы не помещаем никакой IP в данные события. Вы можете полностью отключить аналитику в настройках.

ЧТО VPS DASHBOARD НЕ ДЕЛАЕТ

Это расширение намеренно сфокусировано на управлении со стороны провайдера.

Оно не:
- Устанавливает агента внутри вашего VPS
- Постоянно отслеживает время работы
- Заменяет платформы мониторинга
- Загружает или собирает ваши API-учётные данные или конфигурацию сервера

НАЧАЛО РАБОТЫ

Когда вы впервые открываете расширение без настроенных серверов, экран «Начало работы» спрашивает, к какому провайдеру вы хотите подключиться. Выберите один — откроются настройки с уже выбранным типом провайдера. Можно пропустить и добавить сервер вручную:

1. Откройте настройки расширения
2. Добавьте профиль сервера
3. Выберите тип провайдера
4. Введите конечную точку API и учётные данные
5. Проверьте соединение
6. Откройте всплывающее окно для просмотра статуса и выполнения действий

Подробные инструкции по настройке для каждого провайдера доступны в руководствах внутри расширения.

ОБРАТНАЯ СВЯЗЬ

Пожелания по функциям, сообщения об ошибках и отчёты о совместимости с провайдерами приветствуются. Используйте встроенную ссылку обратной связи в расширении, чтобы создать заранее заполненный issue на GitHub.

Не указывайте в публичных отчётах API-ключи, секреты, токены, IP-адреса, имена хостов или любую другую чувствительную информацию.
