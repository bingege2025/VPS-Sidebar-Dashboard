## English

This Privacy Policy describes how the **VPS Dashboard** extension (referred to as "the Extension") handles user information.

### 1. What Data We Collect
The Extension does **not** collect your API credentials, API URLs, API keys, API hashes, API tokens, cloud secret keys, hostnames, IP addresses, instance IDs, server aliases, browsing history, or VPS content. As with any request to a third-party service, Google Analytics receives the network IP address used to send each anonymous usage event; we do not place any IP address in the event data itself.

The Extension may collect anonymous feature-usage events through Google Analytics 4 Measurement Protocol. Examples include opening the extension, testing a connection, saving a server profile, clicking refresh/reboot/shutdown, exporting/importing configuration, viewing a setup guide, or using feedback links. These events include the feature name and provider type only, such as `aws_ec2`, `solusvm_v1`, `virtfusion`, or `virtualizor`.

The Extension stores a random anonymous client identifier in `chrome.storage.local` only to de-duplicate usage events. This identifier is not linked to your server configuration or personal identity.

### 2. What Data We Store Locally
The Extension stores your API credentials (including API URL, API Key/Token, API Hash/Secret, cloud region, and related configuration preferences) locally on your device using Chrome's secure storage API (`chrome.storage.local`). This information is required to communicate with the VPS provider or control panel endpoint you configure.

### 3. Network Requests & Third Parties
Provider API requests generated by the Extension are sent **directly** to the provider API endpoints specified by you in the settings. Your VPS credentials and server configuration are not routed through or cached on any proxy server.

Anonymous feature-usage events may be sent directly from the Extension to Google Analytics. These analytics events do not contain provider API credentials, API endpoints, server hostnames, instance IDs, or server aliases. As with any request sent to a third-party service, Google Analytics receives the IP address used to transmit each event; we do not place any IP address in the event data itself, and we recommend enabling IP anonymization in the GA4 property.

### 4. Data Security & Control
Since all data is stored locally on your device, you have complete control over it. You can clear all saved credentials and configurations at any time by:
- Clicking the "Delete" option in the settings page.
- Uninstalling the Extension from your Chrome browser.

### 5. Contact Info
If you have any questions or feedback regarding this Privacy Policy, please open an issue at:
[GitHub Repository](https://github.com/bingege2025/VPS-Sidebar-Dashboard)

## 简体中文

本隐私政策描述了 **VPS Dashboard** 浏览器扩展（以下简称“本扩展”）如何处理用户信息。

### 1. 收集的数据
本扩展**不会**收集您的 API 凭证、API URL、API Key、API Hash、API Token、云服务 Secret Key、主机名、IP 地址、实例 ID、服务器别名、浏览历史或 VPS 内容。与任何发往第三方服务的请求一样，Google Analytics 会收到用于发送匿名使用事件的网络 IP 地址；我们不会在事件数据本身中写入任何 IP 地址。

本扩展可能会通过 Google Analytics 4 Measurement Protocol 收集匿名功能使用事件，例如打开扩展、测试连接、保存服务器配置、点击刷新/重启/关机、导出/导入配置、查看配置指南或点击反馈链接。这些事件只包含功能名称和供应商类型，例如 `aws_ec2`、`solusvm_v1`、`virtfusion` 或 `virtualizor`。

本扩展会在 `chrome.storage.local` 中保存一个随机匿名客户端 ID，仅用于区分匿名使用事件。该 ID 不会与您的服务器配置或个人身份绑定。

### 2. 本地存储的数据
本扩展使用 Chrome 的本地安全存储 API (`chrome.storage.local`) 将您的服务器配置信息（包括 API URL、API Key/Token、API Hash/Secret、云区域等 API 凭证和配置偏好）存储在您的本地设备上。这些信息仅用于向您自己配置的 VPS 服务商或控制面板 API 发起请求。

### 3. 网络请求与第三方
本扩展产生的服务商 API 请求会**直接**发送到您在配置页面中填写的服务商 API 接口。您的 VPS 凭证和服务器配置不会通过第三方代理服务器，也不会缓存在第三方服务器中。

匿名功能使用事件可能会从扩展直接发送到 Google Analytics。这些统计事件不会包含服务商 API 凭证、API 地址、服务器主机名、实例 ID 或服务器别名。与任何发往第三方服务的请求一样，Google Analytics 会收到用于传输该事件的网络 IP 地址；我们不会在事件数据本身中写入任何 IP 地址，并建议在 GA4 媒体资源中开启 IP 匿名化。

### 4. 数据安全与用户控制
由于所有配置数据都存储在您的本地设备中，您对此拥有完全控制权。您可以通过以下方式随时清除所有保存的凭证和配置：
- 在扩展程序的选项/设置页面中点击删除服务器。
- 从您的 Chrome 浏览器中卸载本扩展程序。

### 5. 联系我们
如果您对本隐私政策有任何疑问或建议，请在我们的项目主页提交反馈：
[GitHub 项目主页](https://github.com/bingege2025/VPS-Sidebar-Dashboard)
